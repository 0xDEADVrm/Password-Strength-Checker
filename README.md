# Password Strength Checker

## 1. Project Title
**Password Strength Checker using Python**

## 2. Objective
To develop a simple Python program that checks password strength by analysing its length, uppercase letters, lowercase letters, numbers, and special characters.

## 3. Basic Features
- Checks password length.
- Identifies uppercase and lowercase letters.
- Detects numeric characters.
- Detects special characters.
- Calculates a password strength score.
- Displays password strength: Very Weak, Weak, Moderate, Strong, or Very Strong.

## 4. Technologies Used
- Programming Language: Python 3
- Operating System: Kali Linux / Ubuntu
- Concepts: String Operations, Loops, Conditional Statements, Boolean Variables.

## 5. Installation and Execution

Install Python 3:

```bash
sudo apt update
sudo apt install python3 -y
```

Clone the repository:

```bash
git clone https://github.com/USERNAME/Password-Strength-Checker.git
cd Password-Strength-Checker
```

Run the program:

```bash
python3 password_checker.py
```
